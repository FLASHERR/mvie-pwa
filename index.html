Terminarz przeglądów

Ta aplikacja wymaga logowania — dzięki temu każdy klient jest widoczny wyłącznie dla Ciebie, na wszystkich Twoich urządzeniach. Jednorazowa konfiguracja (ok. 5 minut):

  1. Wejdź na console.firebase.google.com i utwórz nowy, darmowy projekt.
  2. Dodaj w nim aplikację webową (ikona </>).
  3. Włącz Firestore Database (tryb produkcyjny) oraz Authentication → Adres e-mail/Hasło.
  4. W zakładce Firestore → Reguły wklej i opublikuj: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/clients/{clientId} {
      allow read, write: if request.auth != null
                          && request.auth.uid == userId;
    }
  }
}
  5. W ustawieniach projektu skopiuj obiekt firebaseConfig i wklej go poniżej.
  6. Opcjonalnie: po zalogowaniu, w panelu "Konto" możesz dodatkowo włączyć App Check (dodatkowa ochrona bazy przed botami).

Konto dla tej aplikacji zakłada się wyłącznie ręcznie w konsoli Firebase (Authentication → Users → Add user) — appka celowo nie ma opcji samodzielnej rejestracji, żeby korzystać z niej mógł tylko ten, komu sam założysz dostęp.

Dodaj do ekranu głównego (iPhone)

  1. W Safari stuknij ikonę Udostępnij (kwadrat ze strzałką w górę) na dolnym pasku przeglądarki.
  2. Przewiń listę opcji w dół i wybierz „Dodaj do ekranu głównego”.
  3. Stuknij „Dodaj” w prawym górnym rogu.
  4. Otwórz aplikację z nowej ikony na ekranie głównym — dopiero z niej zadziała przycisk powiadomień. To ograniczenie systemu iOS, nie tej aplikacji.

Uwaga: żeby dodawanie do ekranu głównego i powiadomienia działały poprawnie, strona musi być otwarta pod adresem https:// (nie jako lokalny plik otwarty dwuklikiem).
